Nota de diseño · uso interno

Times New Roman vs Playfair Display

La especificación pide Times New Roman como herencia del logo. Aquí el mismo titular con ambas familias y mi recomendación como diseñador.

Cliente · Times New Roman

Hola, soy José María Alfaro.

Cumple la herencia tipográfica del logo. En cuerpos grandes muestra trazos finos algo desafilados en pantalla; el ampersand y la e pierden el carácter editorial que un tipo display moderno aporta.

Recomendación · Playfair Display

Hola, soy José María Alfaro.

Misma silueta serif clásica, pero con remates afilados, contraste trazo-fino moderno y métricas pensadas para web. Conserva el espíritu del logo elevando la percepción de marca.

Argumentos para mover al cliente a Playfair Display

  • Times New Roman es una fuente de sistema diseñada para impresión periodística (1932) — su renderizado web carece del contraste afilado que se espera de una marca premium.
  • Playfair Display es open-source (Google Fonts), libre de licencia, optimizada para titulares grandes y con métricas equivalentes a TNR — herencia visual respetada.
  • Mejor jerarquía: la x-height y el contraste de Playfair separan más limpiamente headline, eyebrow y cuerpo, clave en un sitio editorial con mucho espacio negativo.
  • Coherencia con el sector private banking: las firmas de banca privada emplean serifas modernas con remates afilados, no TNR.
  • El logo seguiría siendo el "ancla" Times — Playfair únicamente para titulares de página: la marca permanece intacta, sólo elevamos la web.
