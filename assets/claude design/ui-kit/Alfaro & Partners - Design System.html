— 07 / Arquitectura

Cómo se monta en Astro

Dos archivos, un punto de entrada en el layout base. Cada componente Astro puede sumar su propio bloque <style> scoped sin colisiones.

Estructura 
src/
├─ layouts/
│   └─ BaseLayout.astro    ← importa ambos
├─ styles/
│   ├─ tokens.css          ← variables CSS
│   └─ components.css      ← reset + componentes
├─ components/
│   ├─ Header.astro
│   ├─ Hero.astro
│   ├─ Card.astro
│   └─ …
└─ pages/
    ├─ index.astro
    ├─ firma.astro
    ├─ servicios.astro
    └─ vision/
        └─ [slug].astro     ← Content Collections
